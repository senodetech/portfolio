## 🚀 Quick Start & Local Preview

To run the portfolio locally without any build tools or dependencies:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/senodetech/portfolio.git
   cd portfolio
   ```

2. **Open in browser**:
   - Double-click `index.html`, or
   - Run a lightweight static server:
     ```bash
     # Using Python
     python -m http.server 3000

     # Using Node npx
     npx serve .
     ```
3. Visit `http://localhost:3000` in your browser.
